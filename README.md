# Kaizen Masterpiece Projects — Full Website

## Files
- `index.html` — complete responsive website and company profile content
- `styles.css` — black/yellow styling, responsive layouts, motion, and rotating CSS 3D building
- `script.js` — mobile navigation, scroll reveals, form validation, email draft and WhatsApp fallback
- `assets/` — original client logo and three client construction photos, enhanced/upscaled for display

## Preview locally
1. Extract this folder.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Keep the `assets` folder beside `index.html`; do not move or rename the files.

## Publish on GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the complete `assets` folder to the repository root. In GitHub, open **Settings → Pages**, select the deployment branch and `/ (root)`, then save.
